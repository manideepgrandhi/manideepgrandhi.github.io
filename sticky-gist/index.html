How Gist sync works

Optional. Notes always live in this browser. When sync is on, a copy is kept in one secret gist in your own GitHub account, in a file called sticky-pad-notes.enc.json, with the description sticky-pad-gist-sync (encrypted). There is no server: this page talks to GitHub directly.

Why the link doesn't matter: a secret gist can be opened by anyone who has its link, so the file only ever holds scrambled text. Before anything is uploaded, your notes are encrypted in this browser with AES-256-GCM, using a key made from your passphrase (PBKDF2-SHA256, 600,000 rounds, random salt, fresh random IV on every save). Someone with the link, or GitHub itself, sees only {"v":1, "salt":…, "iv":…, "ct":…}. The passphrase never leaves your device and is never saved. If you tick Remember on this device, the browser keeps a derived key that page scripts can use but can't read out.

When it syncs: when the page opens, about 3 seconds after you stop changing notes, when you come back to the tab, when the device reconnects, and when you tap Sync now. For each note the newest change wins, and a deleted note stays deleted on every device (deletions are remembered for 30 days).

Make a GitHub token (about 2 minutes)

  1. Open GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). The link pre-ticks the scope.
  2. Give it a note such as Sticky Pad Gist Sync and pick an expiry (for example 90 days or 1 year).
  3. Tick only gist (“Create gists”). Leave everything else, especially repo, unticked.
  4. Click Generate token and copy it (it starts with ghp_). GitHub shows it only once.
  5. Here, click Connect GitHub Gist, paste the token, choose a passphrase, confirm it, and click Connect. On your other devices, paste a token (the same one or another gist-only token) and the same passphrase.

Fine-grained token instead? GitHub's fine-grained tokens have a Gists account permission (pre-filled link: Account permissions → Gists → Read and write; no repository access needed). It should work too, but it hasn't been tested with this page. If your second device can't find the gist, paste the gist ID under Advanced.

Good to know: the token is stored in this browser's local storage, so anyone using this browser profile could copy it. With gist-only access it can't touch your repositories. Disconnect forgets the token and key on this device and keeps your notes. To stop sync completely, revoke the token on GitHub. Notes on this device are stored unencrypted in the browser, the same as the plain Sticky Pad, and Export files are not encrypted.
