Start & Stop SQL Services through command prompt

cmdservices

Starting SQL Services

SQL:

net start mssql$blr

net start mssqlserver

SQL Agent:

net start SQLSERVERAGENT

net start SQLAgent$blr
Stopping SQL Services
SQL:
net stop mssql$blr

net stop mssqlserver

SQL Agent:

net stop SQLSERVERAGENT

net stop SQLAgent$blr
