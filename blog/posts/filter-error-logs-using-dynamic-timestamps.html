Filter error logs using dynamic timestamps

errorlogscripts

The below code snippet helps us to retrieve the SQL error log as well as SQL agent log depends on the input parameters passed for a specified time lines.so we can lookout for logs for a given time lines instead of pulling all the logs from day one.

########################
DECLARE @start DATETIME, @end DATETIME
SET @start=DATEADD(DAY,-1,GETDATE());
SET @end=GETDATE();
EXEC xp_readerrorlog 0, 1,NULL,NULL,@start,@end,'Desc'
--0,1 represents latest SQL error log
--0,2 represents latest SQL agent log
GO
