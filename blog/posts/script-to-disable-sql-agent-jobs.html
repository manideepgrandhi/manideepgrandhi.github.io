Script to disable SQL agent jobs

scripts

To disable particular job use the below script

​USE MSDB;
GO
UPDATE MSDB.dbo.sysjobs
SET Enabled = 0
WHERE [Name] ='jobname';
GO
To disable all active jobs please use below code snippet.
UPDATE MSDB.dbo.sysjobs
SET [enabled] = 0
WHERE [enabled] = 1
