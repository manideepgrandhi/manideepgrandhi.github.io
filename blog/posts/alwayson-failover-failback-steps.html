Alwayson failover & failback steps

alwayson

Planned Manual Failover Steps/DR Failover Testing

1. Connect to Primary Instance Name (Not to AlwaysON Listener) and execute below script

USE [master]
GO
ALTER AVAILABILITY GROUP [IADB-P1AG1]
MODIFY REPLICA ON N'IADB-PO-P01V1\POV1' WITH (AVAILABILITY_MODE = SYNCHRONOUS_COMMIT)
GO
ALTER AVAILABILITY GROUP [IADB-P1AG1]
MODIFY REPLICA ON N'IADB-AS-P01V1\ASV1' WITH (AVAILABILITY_MODE = SYNCHRONOUS_COMMIT)
GO

2. Verify DR database is in “Synchronized” state instead of “Synchronizing” State

3. Connect to DR instance and execute below script

USE [master]
ALTER AVAILABILITY GROUP [IADB-P1AG1] FAILOVER
GO
ALTER AVAILABILITY GROUP [IADB-P1AG1]
MODIFY REPLICA ON N'IADB-PO-P01V1\POV1' WITH (AVAILABILITY_MODE = ASYNCHRONOUS_COMMIT)
GO
ALTER AVAILABILITY GROUP [IADB-P1AG1]
MODIFY REPLICA ON N'IADB-AS-P01V1\ASV1' WITH (AVAILABILITY_MODE = ASYNCHRONOUS_COMMIT)
GO

Unplanned Failover/ Primary instance becomes inaccessible due to network or disk related issues

If cluster is online:

1. Connect to DR instance (Not to AlwaysOn listener) and Execute below script in DR instance to bring the Listener and db online

ALTER AVAILABILITY GROUP [IADB-P1AG1] FORCE_FAILOVER_ALLOW_DATA_LOSS;

2. When primary instance comes online, execute below script on
ALTER DATABASE [TC8_External] SET HADR RESUME; TC8_External is the database name

If cluster is not online:

1. Connect to an accessible node.

2. Confirm that any mount points/disks that should be present on the node are there.

a. If they are not present, reboot the accessible node(s) and check to confirm that the disks come online.

3. Open Failover Cluster manager and try to connect to the cluster on that machine.

4. If it does not load, attempt to execute this code from powershell. Replace AlwaysOnSrv02 with the node of your RDP session.

Import-Module FailoverClusters
$node = "AlwaysOnSrv02"Stop-ClusterNode –Name $nodeStart-ClusterNode –Name $node -FixQuorum
(Get-ClusterNode $node).NodeWeight = 1
$nodes = Get-ClusterNode -Cluster $node$nodes | Format-Table -property NodeName, State, NodeWeight

From <https://msdn.microsoft.com/en-us/library/hh270275(v=SQL.110).aspx>

5. Once the cluster is online, revert back to the steps under "if cluster is online" above.
